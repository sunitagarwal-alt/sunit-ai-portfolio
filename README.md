# Sunit Agarwal — AI Portfolio

Next.js + Tailwind portfolio, ready for Vercel.

## Local development

```bash
npm install
npm run dev
```

## Add a project

1. Add a thumbnail to `public/projects/`.
2. Add a record to `src/data/projects.ts` with title, thumbnail, liveUrl, and order.
3. Commit and push to GitHub. Vercel redeploys automatically once connected.

Projects: [Setu for NRI](https://setu-web-beta.vercel.app/) and [Palm reading](https://palmreading-orpin.vercel.app/).
